🚀 Rocket Switch Configurator

Customize each switch's action per mode, then download and move the configuation file to the board.

This tool generates a config.py file for use with the matching code.py. Drag the file to your CIRCUITPY drive. Pressing both buttons simultaneously cycles through the 3 modes — each indicated by LED color.
To learn more about the Rocket Switch Interface and request or build a device, visit the Makers Making Change project page.
View the source code on GitHub: github.com/loretod/Rocket-Switch-Interface
